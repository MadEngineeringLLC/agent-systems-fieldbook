# ADR-0001: Use “Agent Systems Fieldbook”

- **Status:** accepted
- **Date:** 2026-08-25

## Context

The project needs to preserve historical agent artifacts while remaining practical, current, and oriented toward reuse. “Archive” accurately signals preservation but can imply a passive or comprehensive collection.

## Decision

Use the repository name `agent-systems-fieldbook` and the title **Agent Systems Fieldbook**.

## Rationale

“Fieldbook” communicates:

- curated observations rather than indiscriminate accumulation;
- practical mechanisms and operating notes;
- a living document that changes with evidence;
- usefulness to practitioners and researchers;
- room for journal entries, failure records, and evaluated examples.

The repository retains archive-grade provenance and history without implying that every public artifact belongs here.

## Consequences

- Search descriptions should include “archive,” “prompts,” “skills,” “AGENTS.md,” “MCP,” and “orchestration.”
- The README must explicitly state that the project is not an awesome list.
- Completeness is measured by coverage of useful mechanisms, not source volume.
