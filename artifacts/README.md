# Accepted artifacts

This directory contains only accepted, public, attributable artifacts that pass the current evaluation gates.

## Entry contract

Each artifact is a Markdown file with YAML front matter conforming to `schemas/artifact.schema.json`. The body provides:

- a concise mechanism summary;
- operating context;
- implementation or adaptation guidance;
- safety and failure analysis;
- facts, inferences, and unknowns;
- improvements;
- complete attribution.

The generated `catalog/` indexes accepted entries. Do not add watch, rejected, or quarantined candidates here.

## Trust warning

Acceptance means the entry met this repository’s quality gate at a stated time and rubric version. It is not a universal safety certification. Verify current product behavior and adapt permissions before use.
