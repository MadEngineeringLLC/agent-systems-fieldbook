# Agent systems journal

The journal records changes in the agent-system landscape and in the fieldbook itself. It is evidence-led and date-bounded; it is not a stream of generalized AI news.

## Weekly entry structure

Each entry should include:

- period covered and publication time;
- sources reviewed and accepted artifact IDs;
- verified product, protocol, or practice changes;
- emerging mechanisms with supporting sources;
- notable failures, corrections, and safety lessons;
- changes made to the fieldbook;
- category and evidence gaps;
- next watchlist;
- facts, inferences, and unknowns.

## Publication rules

- Prefer primary sources.
- Record both publication date and underlying event date when they differ.
- Link claims to sources.
- Do not infer a trend from one post.
- Do not copy source text into the journal.
- Mark corrections visibly and preserve Git history.
- Do not publish an item merely because it received high engagement.

The machine index is `journal/index.jsonl`.
